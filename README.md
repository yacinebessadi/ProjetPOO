🚗 Carpool System – Java Project
A university group project built using Object-Oriented Programming (OOP) in Java.

💼 Key Skills & Concepts
✅ Object-Oriented Programming (Encapsulation, Inheritance, Polymorphism)

📦 Data Structures: Lists, HashMaps, Queues for managing users and rides

🤝 Teamwork: Assigned tasks, collaborated effectively, respected deadlines

🧠 Problem Solving: Designed a system with user registration, trip creation, ride booking

🧪 Testing & debugging of core features like booking logic and user input
how to run:
javac src/entities/Main.java  
java src.entities.Main
